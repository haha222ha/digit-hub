# 小红书推广 · 分销 SaaS 引导页设计

> 目标：从小红书笔记/私信引流到 **一条清晰路径** ——  
> **闲鱼购买（你提供跳转链接）** 或 **官网在线支付**。  
> 关联全景：`docs/SITE_MAP_XHS365.md`

---

## 1. 产品是什么（对外一句话）

**心象测分销 SaaS**：注册后台 → 购买/兑换额度 → 选测题生成链接 → 在小红书/闲鱼卖给 C 端做测试。  
**不是**源码、不是单条测题卡（那是另一条 SKU）。

现有 SaaS 首页：https://psy.xhs365.cn/（`apps/psy-dist/index.html`）  
偏「测题体验 + 商家入驻」，**缺少**「买额度」的双通道强引导。

## 2. 推荐信息架构

### 2.1 新建公开引导页（建议 URL）

| 候选 URL | 推荐 | 说明 |
|----------|------|------|
| **`https://psy.xhs365.cn/get`** | ✅ 首选 | 短、好记、适合笔记「链接在主页」 |
| `/buy` | 备选 | 语义更直 |

### 2.3 两通道行为

| 通道 | 按钮 | 跳转 | 购后动作 |
|------|------|------|----------|
| **闲鱼** | 去闲鱼购买 | `xianyu_shop_link`（超管配置，按 SKU 可多个） | 自动/手动收 **激活码** → `/admin/redeem-quota` |

## 3. 与现有系统的衔接（不必推倒重来）

### 3.1 已有能力可直接复用

| 能力 | 已有位置 |
|------|----------|
| 在线支付 UI | `/admin/purchase-quota` + 易支付/Waffo |
| 闲鱼兜底弹窗 | `admin.js` → `openXianyuModal(cfg)` |
| 闲鱼店链配置 | `dist_site_config.xianyu_shop_link` |
| 兑换激活码 | `/admin/redeem-quota` |
| 公开定价文案 | `index.html#pricing`、`/pricing/` |
| 自动补卡 | 发货机 `xy_card_bridge.py` |

### 3.2 需要新增的最小集（实现清单）

1. **静态页** `apps/psy-dist/get/index.html`（或 `get.html` + nginx）
2. **公开配置 API**（无需登录）例如：  
   `GET /api/v1/public/dist/purchase-options`  
   返回：`xianyu_links[]`（按规格）、`online_plans[]`、`redeem_url`、`register_url`
3. **超管可配** 多闲鱼链接（可选字段）：  
   `xianyu_link_100` / `xianyu_link_500` / `xianyu_link_2000`  
   或 JSON `xianyu_sku_links`
4. **nginx** 增加 `location = /get { ... }` 或静态目录
5. **小红书笔记统一口令**：「打开 psy.xhs365.cn/get 选购买方式」

### 3.3 配置项建议（dist_site_config 扩展）

| key | 示例 | 用途 |
|-----|------|------|
| `xianyu_shop_link` | 已有 | 默认闲鱼店/主商品 |
| `xianyu_link_quota_100` | 新增 | 100 次规格直链 |
| `xianyu_link_quota_500` | 新增 | 500 次 |
| `xianyu_link_quota_2000` | 新增 | 2000 次 |
| `promo_hero_title` | 新增 | 引导页标题 A/B |
| `promo_online_enabled` | `true` | 是否展示在线支付卡片 |

## 4. 小红书投放路径（运营 SOP）

```text
小红书笔记/私信
    ↓
https://psy.xhs365.cn/get?utm_source=xhs&sku=500
    ↓
┌─────────────┬──────────────┐
│ 闲鱼        │ 在线支付        │
↓             ↓
闲鱼 item     register → purchase-quota
自动发码       微信/支付宝
↓             ↓
redeem-quota  额度到账
    └─────┬─────┘
          ↓
    generate-link → 小红书/闲鱼卖 C 端测题
```

**笔记话术要点：**

- 写清「**分销额度 SaaS**」「生成链接去卖测题」
- 不写 lingbo 原站、不写破解、不写医疗诊断
- 闲鱼档写「激活码自动发」；官网档写「在线支付秒到账」

## 5. 与 Cloud Tunnel / 双机分工

| 环节 | 跑在哪 |
|------|--------|
| 用户打开 `/get`、注册、在线支付 | **ECS**（psy.xhs365.cn） |
| 闲鱼自动发激活码 | **发货机** + bridge（Tunnel 或内网均可） |
| 云端 mint 激活码 | ECS API + Sync Key（Key 在运维机/发货机） |
| 本机 digit-hub 开发 | 只 push 代码，不承载公网流量 |

小红书外链 **只指向 ECS 域名**，不要指向 Tunnel 临时域名（易变、难备案叙事）。
